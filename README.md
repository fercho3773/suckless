This repository is a software collection of my personal forks of suckless software and related tools. 
Each directory is a independent project with its own patches and configurations.

```
software/
├── blocks/
├── dwm/
├── menu/
├── slock/
└── terminal/
```
### Description. 
- **dwm** - Dynamic Window Manager.
- **blocks** - Modules for DWM status bar (dwmblocks async).
- **menu** - Menu and launcher for DWM (dmenu).
- **slock** - Simple X11 screenlocker.
- **terminal** — Suckless terminal (st) with some patches.
